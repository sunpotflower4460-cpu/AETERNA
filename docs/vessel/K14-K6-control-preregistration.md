## 何を弁別するか

K6（K6-PR1〜PR3、完了済み）はreafference弁別（自分が出した波が戻る場合と、
外部から同エネルギー・同スペクトルで入る場合の応答差）を測ったが、**回転結合
vs 加算結合という交絡**が残っていた。K14-PR2で作った
`src/pure/world/foreignFieldControl.ts`は、結合の**形式**をK13の実χと厳密に
同じ分布境界・対称Rabi回転に固定したまま、χ'の中身だけを「ψ自身の履歴と
因果的につながらない独立過程（ψ'に駆動されたχ'）」に差し替える。これにより
「回転という結合形式」と「自己由来か外部由来か」という2つの軸を初めて分離
できる。

比較する2条件:

- **自己（self）**: K13の実χ（分布境界・Rabi回転）。`docs/vessel/K14-L3-L4-
  preregistration.md`の「閉鎖系」条件と**同一のconfig**（N=64・同一パラメータ・
  同一seed列）——**再実行しない**。同文書のrunで既に集計済みの結果をそのまま
  再使用する（同じ実験を二重に走らせない）。
- **外部（foreign）**: `runForeignFieldControlTick`。ψ'は独立seedの完全に
  開放系（`runMediumHistoryTick`で直接駆動を受ける、閉鎖系条件のψが受けていた
  のと同じ駆動）。χ'はψ'の場の値を`injectionStrength`倍だけ受け取り、その後
  メインψと分布境界・Rabi回転で結合する。

## 固定するパラメータ（実験を見る前に決める）

| パラメータ | 値 | 選定理由 |
|---|---|---|
| N・α, g, ν₀, κ, ρ・ω・駆動振幅・k・λ・dt・totalTicks・maxDisplacementCells・tau_min | `docs/vessel/K14-L3-L4-preregistration.md`と完全に同一 | 「自己」条件を再利用するため、パラメータが1つでも違えば比較にならない |
| ψ'の固有パラメータ | メインψ・χと同じ物理定数（α, g, ν₀, κ, ρ）、ただしseedはメインψ・χのseedと重複しない独立値（`seed + 3000`） | ψ'は「メインψと同じ物理法則に従うが、履歴は完全に独立」という設計そのもの（`foreignFieldControl.ts`の設計文書コメント参照） |
| ψ'への駆動（foreignDrive） | 「自己」条件でメインψが受けていたのと**同一のω・振幅・位相**（3, 0.3, 0.1） | エネルギー源の強さを条件間で揃える。ψ'が「自己」条件のψの代わりを務める、という対応関係を保つ |
| **injectionStrength** | 1.0 | χ'がψ'の場の値をそのまま（減衰も増幅もせず）中継する、最も単純で調整のない選択。この値を実験結果を見てから調整することはしない。K5の対称結合自体が「増幅なし」を要求するのと同じ精神 |
| seed | 1〜20（「自己」条件と同一のseed列、`docs/vessel/K14-L3-L4-preregistration.md`のものをそのまま使う） | ペアごとの比較を可能にするため |

## 測定する量（K13の遅延線比較で最も情報量があった指標をそのまま再使用）

run終了時のN_ψ、maxPersistenceTicks（`vortexPersistenceAtLeast(tau_min)`）。
新しい測定器は発明しない。

## 決定的反証子の判定基準（実行前に固定）

`docs/vessel/K14-L3-L4-preregistration.md`と同一の判定基準を流用する:
「自己」条件（基準）に対して「外部」条件の中央値N_ψ・中央値maxPersistenceTicks
が**相対差20%未満**であれば「結合形式が同じである限り、自己由来か外部由来かで
メインψの応答は区別できない」と判定する。20%以上なら「区別された」と判定する。

## 誠実な限界（先に述べる）

- 「自己」条件は再実行せず`docs/vessel/K14-L3-L4-preregistration.md`の実行
  結果をそのまま使う。もしその文書のパラメータと本文書のパラメータに食い違いが
  後から見つかった場合は、この比較全体を無効として記録する（黙って近似値で
  代用しない）。
- injectionStrength=1.0はエネルギーを厳密に較正した値ではない。K6本体
  （K6-PR1）が行った「エネルギー・スペクトルを揃える」較正は、ここでは
  簡略化として行わない——結合形式そのものを固定するという本実験の主眼から
  外れるため。将来、較正込みの再実験を行う余地は残る。
- 20 seedは頑健性の確認であり、統計的に確証的な検定ではない。
