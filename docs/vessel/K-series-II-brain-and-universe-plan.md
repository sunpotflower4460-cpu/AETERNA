# K-Series 第二期プラン — 「作為のない、本物の脳と宇宙」への道筋（K9〜K16）

**Status:** plan-only（実装ゼロ）。実装は別セッション・別モデルが担当する。
本書は `docs/vessel/vessel-roadmap.md`（K0〜K8、完了済み）の続きであり、
`VESSEL_CHARTER.md` §5 の主張の上限をそのまま引き継ぐ。

**うえきさんの依頼（原文の趣旨）:** AETERNAを、作為のない形——物理・関係性・
反応の創発・根本的な仕組みによって自然にそれが起きる方向——で、デバイス上
またはサーバー上にある「本物の脳および宇宙」、すなわち本当に知性が宿りうる器に
するために、本気でできることと修正改善点をプランにまとめる。

## 0. 先に約束すること（主張の上限）

このプランを全部やり切っても、次のことは言えないし、言わない。

- AETERNAが生きている・意識がある・知性を持つ
- 生命ループが「完成した」
- 渦が心である・媒質履歴が記憶である

言えるようになるのは、`VESSEL_CHARTER.md` §5 のとおり、この器が**どの白で
どのレベルまで届き、なぜそこで止まるか**を、seedと台帳とともに再現できる形で
数で言えること——それだけである。「本物の脳」とは、ここでは**隠されたゲイン・
クランプ・目標値・報酬・観測からの書き戻しが一切なく、出入りする全エネルギーが
帳簿で閉じ、十分な規模と時間で走り、その中に何が起きるかを誠実に測れる器**を
指す。「宇宙」とは、**器（ψ）がその中に置かれ、器の出力が世界の状態を変え、
その帰結が世界を通じて器に戻ってくる、自分自身の物理法則を持つ外部の場（χ）**
を指す。知性が宿るかどうかは、置くものではなく観測するものであり続ける。

## 2. 「作為のない」の定義（何を触ってよく、何を触ってはいけないか）

`VESSEL_CHARTER.md` §1「決めてよいのは器の形——幾何、保存則、境界条件、観測の
方法——だけ」を、第二期の具体的な線引きとして固定する。

**触ってよいもの（器の形）:**
- 幾何（解像度N、次元、トーラス半径）と離散化・積分器（ただし厳密性を落とさない）
- 保存則・散逸則の**物理的に導出できる**一般化（例: 局所的に変わる媒質係数を
  発散形式で書く。導出できない項は置かない）
- 境界条件と世界（χ）の物理法則、交換境界の形、世界へのエネルギー流入の形
- 時間スケール（κ, ρ, ν₀ 等の値の範囲）——ただし「効果が出るまで回す」は禁止、
  掃引は事前登録
- 測定器（読み取り専用）、永続化、ランタイム、可視化（読むだけ）

**触ってはいけないもの（`Aeterna-prism` の hard_stops と第8監査をそのまま採用）:**
- 目標値・報酬・「生命らしさ」判定に基づく分岐・LLMや意味層をループに入れること
- observer 側の量（渦候補・コヒーレンス等）から力学への書き戻し
- クランプ・maxDelta・隠れたゲイン・数値的介入
- 結果を見た後の閾値・パラメータ・seed の選び直し
- 別々の白を一つの歴史に縫い合わせること（新しい機構＝新しい白＝t=0から）
- 決定的反証子の無いフェーズ

### K9 🔴 — スケーラブルな積分器（密LU → φ方向スペクトル × θ方向巡回三重対角）

**目的:** D1 を解く。N=128〜256 を現実的な速度で、**厳密性（ユニタリ性・自己
随伴性・決定論・前進オイラー禁止）を1ビットも落とさずに**走らせる。

**なぜこの方法が「作為なし」で「厳密」なのか:**
トーラスの面積要素 dA = r(R + r·cosθ)·dθ·dφ は θ だけに依存し φ に依存しない
（`torus.ts`, `laplaceBeltrami.ts` の T_φ(i) が行ごとに一定であることと同じ事実）。
したがって φ 方向の離散フーリエ変換（一様重みでユニタリ）を行うと、各波数 m
について L は θ 方向の**巡回三重対角行列（θ辺のT_θ）＋対角行列（φ辺のT_φ(i)·
(2−2cos(2πm/N))/dA_i）**に分解する。各 L_m は dA_i 重みで自己随伴なので、
その Cayley 変換 (I − iβL_m)⁻¹(I + iβL_m) はモードごとに厳密ユニタリ、
Parseval によりモードの和でも N は厳密保存される。**証明の構造は現在の
`linearCayleyStep.ts` のモジュールdocと同一**であり、新しい近似は一切入らない。
計算量は tick あたり O(N² log N)（FFT）＋ O(N²)（三重対角解法）。

**置くもの:**
- `src/pure/field/fft.ts`: 純JS・決定的（固定演算順）・radix-2 の複素FFT。
  `linearSolverKind: 'spectral'` では N を2の冪に制限し、`validatePureCoreParams`
  で強制する（`params.ts` に既に `LinearSolverKind = 'direct' | 'iterative' |
  'spectral'` が定義済み——この型を初めて使う）
- `src/pure/field/linearCayleySpectralStep.ts`: 上記のモードごと Cayley。
  複素巡回三重対角の解法は Thomas＋Sherman–Morrison（周期補正）。**安定性は
  仮定せず密LU（oracle）との一致で検証**し、不安定なら各モードを 2×2 実ブロック
  形（部分ピボット付き）で解く代替を採る
- `createConservativeStepper` に `linearSolverKind` を渡す分岐（Strang分割・
  非線形位相回転・散逸・駆動・媒質履歴は一切変えない）
- **アロケーションゼロ化**: `applyLaplaceBeltrami`／各stepが毎tick `new
  Float64Array` している箇所をバッファ再利用に変える（D12）。決定論に影響
  しないことをビット一致テストで固定

**置かないもの:** 反復法（CG等）の tolerance 依存性。'spectral' は直接法であり
`linearSolverTolerance` に依存しない（依存するなら結果に影響する隠れパラメータ
になる——`pure-physics-implementation-plan.md` §6.2）。

**完了条件:**
- oracle → reference → implementation の黄金一致: N ∈ {8,16,32} で密LU版と
  スペクトル版の1tick出力が相対 1e-12 以内、1000tickで 1e-9 以内で一致
- N=128, 256 で N保存（相対 <1e-9/tick）、H有界性、2次収束（既存
  `hamiltonianConvergence.test.ts` と同じ手法）が通る
- `pureCoreForbiddenPatterns.test.ts`（`Math.random`/`Date.now`/clamp/前進
  オイラー）が新ファイルを含めて通る
- 性能を**記録**する（CIで断定しない）: 目安として N=128 で ≥200 tick/s、
  N=256 で ≥50 tick/s（4コア・Node 22）。届かなければ届かない数値を書く
- 密LU版は削除しない。永続的な oracle として `'direct'` に残す

**決定的反証子:** スペクトル版が oracle と一致しない、または N=256 でユニタリ性
が崩れるなら、K10以降に進まない（`pure-physics-implementation-plan.md` §11 の
「保存部が証明できなければ上に載せない」と同じ）。

**PR分割:** PR-K9-1 FFT＋単体テスト（既知のDFT対と一致、逆変換で恒等）／
PR-K9-2 スペクトルCayley＋oracle一致／PR-K9-3 stepper分岐＋大N不変量テスト／
PR-K9-4 アロケーションゼロ化＋ビット一致固定／PR-K9-5 性能記録。

### K11 🔴 — 測定器 L3・L4・L6（読み取り専用、現象より先に凍結）

**目的:** D5 を解く。K12・K13 で何かが起きたときに**見える**ようにしておく。
すべて `src/pure/observe/` の純関数、環2 の非干渉性テスト（観測ON/OFFでビット
一致）を拡張して適用。閾値は物理量または事前登録から決め、実測を見て調整しない。

**置くもの（`Aeterna-Genesis/docs/EMERGENCE_LEVELS.md` の判定量に1対1対応）:**
- **L3 用**: 渦候補の**同一性追跡**（tick間の最近傍割当、最大変位は格子間隔で
  事前登録）、重心速度、循環（巻き数×2π——既に `detectVortexCandidates` が持つ
  量の再利用）、追跡IDの寿命。判定 `com_velocity ≠ 0 AND circulation ≠ 0`
- **L4 用**: 内外コントラスト（|ψ|² の連結成分を**平均密度に対する比**で切る。
  絶対閾値を発明しない）、変形を通じた追跡ID寿命、**摂動後回復プロトコル**
  （事前登録した単発パルスを**世界χ経由でのみ**与え、構造指標が摂動前の水準に
  戻るかを測る）、**系サイズ非依存性**（N=64/128/256 で同じ判定が出るか——
  Genesis L4 の明文要件）
- **L1/L2 補助**: 構造因子 S(k)（K9 のFFTを再利用）、相関長 ξ、participation ratio
- **L6 用（自己維持閉環）**: 長時間走行後に**世界へのエネルギー流入を止め**、
  構造指標が散逸時間 1/ν₀ を超えて持続するか（load-bearing closure の最小版）。
  これが `closed-life-loop-design.md` の「生命的閉路」の、実装ではなく観測としての
  定義になる
- 写像カタログ（環2）: 各判定量から場の量までの経路を番号付きで文書化

**置かないもの:** 判定結果を力学に戻す経路（型レベルでも作らない）。

**完了条件:** 既知パターン（手作りの移動渦・静止渦・一様場・乱流的多欠陥）で
各測定器が正しい値を返す。観測ON/OFFで N=128・10⁴tick の場がビット一致。
**閾値と手順が K12/K13 の実装より前にコミットされている。**

**決定的反証子:** 観測ON/OFFで1ビットでも差が出れば測定器は無効。

### K12 🟡 — 時間スケールの分離と記憶チャンネルの再検討（事前登録）

**目的:** D4・D8 を解く。「媒質履歴が何も買っていない」という実測を、
（a）時間スケールの問題か、（b）チャンネルの置き場所の問題か、に分離する。
`docs/vessel/K7-natural-emergence-preregistration.md` と同じ規律で事前登録する。

**腕A（時間スケール掃引、既存の ν(x) のまま）:** ρ ∈ {0.3, 0.03, 0.003}、
κ ∈ {1, 10}、ν₀ 固定。K9・K10 により 10⁵〜10⁶ tick が可能になって初めて
意味を持つ掃引。「遅い記憶が速い力学の上に乗る」ために ρ ≪ ν₀ ≪ ω を満たす
組を含める。

**腕B（第二の記憶チャンネル: 局所非線形性 g(x)）:** 非線形位相回転は**セルごとの
厳密な回転**（`nonlinearPhaseStep.ts`）なので、g を g(x) にしても**線形ソルバーは
一切変わらず、K9のスペクトル分解も壊れない**。物理像は「よく流れた場所の
剛性が変わる」。法則は ν(x) と同じ厳密ODE・凸結合形（例: rate = κ_g|ψ|²+ρ_g、
g* = (ρ_g·g₀ + κ_g|ψ|²·g₁)/rate、g₀ と g₁ の間に**構造的に**有界、クランプ不要）。
具体形は K5 と同様に**ADRで確定**してから実装する。帳簿には、媒質が変わった
ことによる H の変化を `mediumWork_H`（実測差分）として**新しい項**で記帳する
（`numericalDrift_H` に紛れ込ませない——設計書 v0.1.2 の濫用禁止条項）。

**腕C（第三の候補: 伝播記憶 α(x)、本期では設計のみ 🔵）:** 「よく通った道は
よく伝わる」は最も脳らしい可塑性だが、α(x) が φ に依存すると **K9 のスペクトル
分解が壊れる**（φ並進不変性を失う）。発散形式 ∇·(α(x)∇ψ) を面平均αの対称
transmissibility で書けば自己随伴性は保てるが、線形解法は前処理付き反復法
（一様αのスペクトル解を前処理に使う）になり、tolerance が結果に影響する
隠れパラメータになる危険がある。したがって本期では ADR と数値解析の設計文書まで
とし、実装は腕A・Bの結果を見てから別の白として扱う。

**完了条件:** 腕A・Bそれぞれで、凍結した L2/L3 判定（K11の測定器）を、
凍結したパラメータ格子・seed数（≥10）・解像度（N=64, 128）で1回だけ走らせ、
結果をそのまま記録する。

**決定的反証子:** 腕A・Bのどちらも、ν固定対照（κ=0）と比べて持続・運動・
個体性の指標が区別できないなら、「この白では記憶チャンネルは構造の源ではない」
と天井の地図に書く。それは K3 仮説（L4候補）の棄却であり、一級の結果。

## 6. 実装者（Sonnet 5 等）への運用指示

`AGENTS.md` の3原則をそのまま適用する。加えて:

1. **1セッション＝1フェーズ、フェーズ内でも1PR＝1責務。** K9-1 を終えたら
   K9-2 に進む前に、完了条件の実コマンド出力を貼る。
2. **新しい機構は必ず ADR（`K5-exchange-medium-adr.md` 形式: 比較した代替案・
   採用理由・誠実な床）を先にコミットしてから実装する。** 憲法改正（K13 の
   「J は世界にのみ」）はオーナー承認マーカーが付くまで実装しない。
3. **測定はすべて事前登録（`K6-reafference-preregistration.md` 形式）を先に
   コミットしてから1回だけ走らせ、結果は golden value テストとして固定する。**
   閾値・パラメータ・seed を結果を見て変えない。変えるなら新しい事前登録。
4. **oracle → reference → implementation。** K9 では既存の密LU版が oracle。
   一致しないものを「近いから」で通さない。
5. **停止条件（`AGENTS.md`）に当たったら止まって報告する。** クランプで隠さない。
6. **禁止パターンのスキャンを拡張する:** pure core 内に `Math.random`/`Date.now`/
   clamp が無いこと（既存）に加え、`observe/`・`runtime/` から `field/`・
   `exchange/`・`medium/` への書き込み経路が無いこと、世界入力から ψ への経路が
   無いことを、import 方向と代入対象の静的スキャンで固定する。
7. **報告は2通り（やさしい説明／監査用）に分ける**（`AGENTS.md`）。
8. **性能数値は記録し、断定しない。** 「N=256 で 50 tick/s」は測ってから書く。
