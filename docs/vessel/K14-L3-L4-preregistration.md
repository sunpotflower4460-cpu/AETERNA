# K14 事前登録 — L3/L4測定: 開放系・閉鎖系・遅延線対照の3条件比較

**Status:** approved-by-continuation（うえきさんの「OK お願いします」を実装

## 比較する3条件

- **開放系（世界なし）**: K2〜K12の直接駆動構成。ψが`runDriveTick`でJを
  直接受け取る（K13の憲法改正前の構成——K13のADRが明記したとおり、
  この構成自体は無効化されておらず、比較対照として引き続き使える）
- **閉鎖系（世界あり）**: K13の実χ（2次元場、分布境界）
- **遅延線対照**: K13の遅延線対照（`delayLineControl.ts`）

## 使用する測定器と誠実な限界（実行前に明記）

**L3**（`trackVortices`/`evaluateL3`）を測定する。ただし**K12で既に判明した
既知の飽和**——`circulation != 0`は`detectVortexCandidates`の設計上つねに
真、`com_velocity != 0`は2tick生存する候補ならほぼ自動的に満たされる——
により、L3満足率は3条件間で意味のある弁別を行わない可能性が高いことを
実行前に明記する。K12と同じく、この床はL3という指標**だけ**の限界であり、
他の指標（下記）まで無効にするものではない。

**直接的な構造指標**（K13の遅延線比較で最も情報量があった指標をそのまま
再使用する。新しい測定器の発明ではない）: run終了時のN_ψ、
maxPersistenceTicks。

**L4の完全な測定（内外コントラスト・変形追跡・摂動後回復・系サイズ非依存性）
は今回実行しない。** 計算資源・時間の都合による、実行前の縮小として
明記する。K11で凍結済みの測定器（`densityContrast.ts`・`blobTracking.ts`・
`perturbationRecovery.ts`）自体はK14の対象外にはならない——将来の追加runで
使用する道はそのまま残る。

## 決定的反証子の判定基準（実行前に固定）

3条件間でN_ψの中央値・maxPersistenceTicksの中央値を比較する。開放系
（外部からの直接駆動を受ける、この計画で最も「餌が豊富な」構成）を基準に、
閉鎖系・遅延線対照それぞれが**相対差20%未満**（K13の判定基準を踏襲）で
あれば「区別できない」、それ以上なら「区別された」と判定する。L3満足
seed数も併記するが、上記の理由により主たる判定には使わない。

## 誠実な限界（先に述べる）

- L4の完全な測定は今回実行しない（上記）
- 系サイズ非依存性はL2の別文書で扱う。本実験はN=64のみ
- 遅延線のdelayTicks・dampingFactorはN=8で測定した値をそのまま流用する
  （分布境界の各対はψ・χ双方の局所的な性質にのみ依存するという想定に
  基づく簡略化であり、N=64で再測定した値とは異なる可能性がある）
- 20 seedは計画の下限要件を満たすが、統計的に確証的な検定（p値等）は
  行わない。中央値の比較という単純な操作化にとどまる
