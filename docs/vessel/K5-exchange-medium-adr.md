# K5 実装ADR — 交換境界𝒮・外部媒質χ・対称結合の具体化

**Status:** approved-by-continuation（うえきさんの「進んでください お願いします」を
実装続行の承認として扱う。技術選択そのものへの異議があれば、この文書を読んだ上で
差し戻すことができる）。`docs/vessel/closed-life-loop-design.md` が要求する
「実装 PR では別途 ADR 相当のレビューを要する」に応じる文書。

`closed-life-loop-design.md` は χ・𝒮・対称結合を**抽象的に**定義した。この文書は
それを実装可能な具体的な数式・データ構造に落とし込む際の選択と、その理由を記録する。
のちに読む人（人間・エージェントを問わず）が「なぜこの形になったか」を辿れるように
することが目的であり、承認を後から取り繕うためのものではない。

## 選択1: χ の「自分自身の波動方程式」は厳密な巡回シフトにする

**選んだもの:** χ は 1 次元の周期リング（M セル、一様間隔 dx_χ）上に定義する。
χ の保存部は、1 tick ごとに配列を `shiftCellsPerTick` セルぶん巡回シフトする
**厳密な移流**（∂χ/∂t = −v·∂χ/∂x の厳密解 χ(x,t)=χ(x−vt,0)）とする。

**比較検討した代替案:**

1. ψ と同型の Schrödinger型分散（i·α_χ·∇²χ）を χ にも与える。
   → 却下。この分散関係 ω=α_χk² は k に依存する群速度を持つため、
   「χ の経路長と波速から往復遅延が導出される」という設計要求（`closed-life-loop-
   design.md`）を**単一の値として**満たせない。特定の k に固定すれば可能だが、
   波束が伝播中に分散し、往復遅延の測定自体が曖昧になる。
2. 有限長の反射壁を持つ1次元導波路（Dirichlet境界での反射）。
   → 却下ではないが今回は選ばない。反射境界の自己随伴性は既存の
   `laplaceBeltrami.ts` と同じ手法で保証できるが、反射のたびに位相・振幅が
   境界条件（Dirichlet/Neumann等）に依存し、「境界条件の選び方」という
   新しい自由パラメータが増える。周期リングなら境界条件そのものが不要になる。

**理由:** 巡回シフトは
- 離散移流方程式の**厳密解**であり数値近似ではない（分散誤差ゼロ）
- 巡回置換なので N_χ を**代数的に**厳密保存する（浮動小数点丸め以外の誤差なし）
- 巡回置換はどのフーリエ成分の振幅 |χ_k| も変えない（位相だけ回す）ため、
  自己随伴な内部ラプラシアンから定義する H_χ = α_χ·<χ,−L_χχ>（g_χ=0の場合）も
  **代数的に厳密に**保存される——ψ側のCayley/CN近似より強い保証であり、
  これはχ側の「誠実な床」として明記する（χは非分散・非減衰の理想的搬送路であり、
  ψ側と同じ意味で「物理的に典型的な媒質」ではない）
- 往復遅延が `M / shiftCellsPerTick` tick という**厳密な整数値**になり、
  「境界条件を先に決めてから遅延が導出される」という設計要求を最も強い形
  （近似ではなく整数一致）で満たせる

**誠実な床:** g_χ=0（χの非線形項は「任意で」なので今回は置かない）。χは分散を
持たない理想的な搬送路であり、現実の媒質が持つ分散・非線形性は表現しない。
これは K5 の目的（戻る道があるかどうかを最小構成で確かめる）に対して十分な
単純化であり、より現実的な χ は将来の拡張として残す。

## 選択2: 交換境界𝒮は単一セルとする

**選んだもの:** 𝒮 = ψ のトーラス上の1セル（外環赤道 θ=0 に最も近いセルとして
幾何的に選ぶ。「効果が良いから」ではなく、θ=0 が dA を最大化する幾何的特異点
であるという、torus.ts が既に持つ量から導かれる基準）。

**比較検討した代替案:**

1. 複数セルからなる分布境界（`closed-life-loop-design.md` の `mask_𝒮(x)` の
   素直な読み方）。
   → 今回は採用しない。χ側の単一ポートセルと複数のψセルを対称に結合する
   厳密にユニタリな結合は、star-graph型のエルミート結合行列（固有値
   ±λ√|𝒮| と (|𝒮|-1)重に縮退した0）になり、解析的に閉じた形は書けるが、
   実装・検証の複雑度が単一セルの場合より大きく増える。

**理由（Genesis の「Level N の後に Level N+1 の機能を追加してはならない」原則）:**
単一セル境界で「戻り道がある/ないで挙動が変わるか」という最小の主張を先に
厳密に検証し、複数セルへの一般化はその後の拡張として残す。

**誠実な床:** 分布境界（複数セル）は実装していない。単一セルは「セルの
部分集合」の最小のインスタンスとして技術的には設計書の定義を満たすが、
「交換境界」という語が本来意図するであろう空間的広がりは持たない。

## 選択3: 対称結合は厳密な2準位「ラビ回転」とする

**選んだもの:** ψ の境界セル `psi_b` と χ のポートセル `chi_p`（リングの
インデックス0）を、エルミートな結合ハミルトニアン `λ·(|psi_b><chi_p| +
|chi_p><psi_b|)` で結合する。この2準位系は厳密に解ける:

```
theta = lambda * dt
psi_b_new = cos(theta)*psi_b_old - i*sin(theta)*chi_p_old
chi_p_new = cos(theta)*chi_p_old - i*sin(theta)*psi_b_old
```

**比較検討した代替案:**

1. `closed-life-loop-design.md` に書かれた素朴な緩和型結合
   `dψ/dt = +λ(χ−ψ)`, `dχ/dt = −λ(χ−ψ)`。
   → 却下。この形は実軸方向の緩和（拡散型）であり、解析すると
   |psi_b|²+|chi_p|² を**保存しない**（`(chi_p-psi_b)`の絶対値の2乗に比例して
   単調に失われる——ちょうど抵抗でつながれた2つのコンデンサが電荷は保存
   するがエネルギーは散逸するのと同型）。「同額逆符号」という帳簿の要求を
   満たすには、測定した値を後から強制的に符号反転させる不誠実な帳簿操作が
   必要になってしまう。

**理由:** ラビ回転はユニタリ変換（2×2エルミート行列の指数写像）そのものなので、
|psi_b|²+|chi_p|² の保存は**代数的な恒等式**であり、数値実験で近似的に確認する
ものではなく証明できる。設計書の「対称結合であれば無からエネルギーを作れない」
という要求を、緩和型よりも厳密な形で満たす。

**帳簿の整合のための追加選択:** χ のリングの dA（`dx_chi`、1セルあたりの
「長さ」重み）を、𝒮 に選んだ ψ の境界セルの `cellArea` と**厳密に一致**させる。
これにより psi_b 側の N 変化（`cellArea_b * Δ|psi_b|²`）と chi_p 側の N 変化
（`dx_chi * Δ|chi_p|²`）が、ラビ回転の Δ|psi_b|²=−Δ|chi_p|² という恒等式から
そのまま「同額逆符号」になる。これは新しい自由パラメータではなく、既存の
2つの幾何（ψのトーラス、χのリング）を整合させるための拘束条件である。

**誠実な床:** ラビ回転もこのままでは前進オイラーと同じ問題を持ちうる
（i×エルミート行列という形は線形シュレディンガー項と同型）。ここでは
**厳密な解析解**（cos/sinの直接計算）を使うことで陽解法/前進オイラーの
不安定性を回避している——`linearCayleyStep.ts`のCayley/CN数値解法とは異なる
やり方だが、`nonlinearPhaseStep.ts`が非線形項に厳密解を使っているのと
同じ考え方である。

## 選択4: tick内ステップ順序への 'exchange' の追加位置

**選んだもの:** `PURE_CORE_SOLVER_STEP_ORDER` を
`['conservative','dissipation','drive','exchange','mediumHistory','observe']`
に変更する（'drive'と'mediumHistory'の間に挿入）。

**理由:** 媒質履歴 ν(x) は「その tick で場を通過した最終的なエネルギー」に
応答するべきである（`docs/pure-physics-implementation-plan.md` PR6の設計）。
交換で出入りしたエネルギーも媒質履歴が応答すべき対象に含めるのが自然なので、
交換は媒質履歴より前に置く。逆に、交換はその tick の保存・散逸・駆動が
確定した後の ψ に対して行うべきなので、conservative/dissipation/driveより後に
置く。

**明示的な変更であることの確認:** `docs/pure-physics-implementation-plan.md`
§9は「tick内ステップ順序を暗黙に変更する」ことを禁止しているが、これは
**明示的な**変更であり、この ADR と対応するテストの更新（
`src/tests/pure/pureReportFormat.test.ts` の `solverStepOrder` 期待値）を
伴う。

## この ADR が答えない問い

- 分布境界（複数セル）への一般化 — 将来の拡張
- χ 自身の媒質履歴（ν_χ(x)、K3と同型）— 将来の拡張、今回は ν_χ を定数とする
- χ の非線形項（g_χ>0）— 今回は置かない
- 複数の χ を持つ場合の設計 — `closed-life-loop-design.md` が明示的に
  「単一の外部媒質による K5〜K6 が完了するまで、複数媒質への拡張は開始
  しない」としている
