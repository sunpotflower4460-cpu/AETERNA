# 閉じた生命ループ設計 — K5 物理的閉路 / K6 生命的閉路観測

**Status:** docs-only. 設計書であり実装ではない。`docs/pure-physics-implementation-plan.md`
に記載のない拡張であるため、実装 PR では別途 ADR 相当のレビューを要する
（`docs/vessel/anti-delusion-apparatus.md` 環4を参照）。

## なぜこの設計が必要か

`docs/pure-physics-implementation-plan.md` が定義する純粋物理コアは**開放系**で
終わっている。

```
∂ψ/∂t = i(α∇²ψ − g|ψ|²ψ) − νψ + J(x,t)
```

J(x,t) は場への唯一の外部入力経路として明記されているが（§1「J(x,t) は場への
唯一の外部入力であり、シナリオとは J の仕様である」）、J は**指定された関数**
であり、場から J への戻り道は存在しない。うえきさんが第一に置いた「閉じた
生命ループ」は、この段階ではまだ成立し得ない。K5 でここに戻り道を置く。

## K5 — 物理的閉路（境界条件として置いてよいもの）

`VESSEL_CHARTER.md` §2 の分類に従い、これは**幾何・境界条件**であって結果では
ない。設計者が置いてよい。

### 構成要素

**交換境界 𝒮**
トーラス上のセル部分集合として、幾何のみで定義する。「効果が良さそうだから」
という理由で選ばない。K2 の `torus.ts` が既に持つセル面積 `dA` と計量情報から
決定される、単なる部分集合である。

**外部媒質 χ**
自分自身の波動方程式と自分自身の散逸を持つ、独立した第二の場。制御器では
なく物理場である。χ には以下が必要:
- χ 自身の保存部（線形分散 + 任意で非線形項）
- χ 自身の散逸率 ν_χ（K3 と同型の媒質履歴を χ 側にも持たせてよいが、
  それは χ 側の新しい白として別途扱う）
- χ 自身の帳簿（N_χ, H_χ）

**対称結合**
ψ↔χ の交換を単一の対称項として書く。片方向だけ可変ゲインを持つ非対称結合
は禁止する。対称結合であれば、結合項は無から正味のエネルギーを作れない
（作れるとすれば帳簿の閉じなさとして即座に検出される）。

```
結合項の型（例）:
  dψ/dt|coupling = +λ·mask_𝒮(x)·(χ − ψ)
  dχ/dt|coupling = −λ·mask_𝒮(x)·(χ − ψ)
```
mask_𝒮 は交換境界 𝒮 上でのみ非ゼロの幾何マスク。λ は結合定数一つのみとし、
方向ごとに別の値を持たせない。

**創発する往復遅延**
`delay` というパラメータを直接置かない。χ の経路長（境界から χ の遠端までの
距離）と χ 自身の波速から、往復遅延が導出される値として出てくることを
要求する。遅延を先に指定して χ の幾何を後から合わせることは禁止する。

### 置かないもの

- 目標値（desiredTarget 系）
- 報酬・評価に基づくフィードバック
- 生命らしさの判定に基づく分岐
- observer 側候補（vortex candidate 等）からの帰還

### 帳簿

2 本（N, H）から 4 本（N_ψ, H_ψ, N_χ, H_χ）へ拡張する。交換項は ψ 側・χ 側の
両方の帳簿に、**同額・逆符号**で記帳される。これは K2〜K4 の開放系の帳簿より
**強い**制約であり、それ自体が実装の反証子になる：もし同額逆符号でなければ、
対称結合の実装に不整合があるということである。

```
N_ψ(t+1) = N_ψ(t) + driveWork_N + exchangeWork_N_ψχ − dissipationLoss_N + residual_N
N_χ(t+1) = N_χ(t)               − exchangeWork_N_ψχ − dissipationLoss_N_χ + residual_N_χ
```
（H についても同型。exchangeWork の符号が両辺で厳密に逆であることをテストで
固定する。）

### 完了条件（`vessel-roadmap.md` より再掲）

- 結合ゼロ（λ=0）で K2〜K4 の開放系結果と bit 一致する（遮断対照）
- 交換項が両帳簿で同額逆符号
- 往復遅延が幾何と波速の予測値と一致する
- `solverStepOrder` に交換ステップが明記され export に含まれる

### 決定的反証子（零仮説）

χ を「同じ遅延・同じ減衰特性を持つが内部力学を持たない遅延線」（すなわち
単純な time-delay buffer）に置き換えても、ψ 側から見た挙動が区別できない
場合、**外部媒質を独立した物理場として置いたことは何も買っていない**。
この場合、χ の物理場としての実装は撤回し、単純な遅延線で十分だったと
記録する。これは失敗ではなく確定した結果である。

## K6 — 生命的閉路の観測（実装しない、測る）

K5 が置いたのは「戻る道」だけである。その道を通って戻ってきた自分の波を、
場が「外からの新規入力」と区別して扱うかどうかは、**実装するものではなく
観測するもの**である。区別が観測されなければ、それが結論になる。

### 主要測定: reafference 弁別

二つの条件を用意する。

**条件A（自己反響）**: ψ が交換境界 𝒮 を通じて χ に放出した波が、χ を経由して
𝒮 に戻ってくる。

**条件B（外部入力対照）**: 条件Aと**同じ 𝒮 上のエネルギー・同じ周波数スペクトル**
を持つ波形を、χ を経由せず直接 𝒮 に注入する。

条件Aと条件Bでエネルギーとスペクトルを揃えることは必須である。揃えなければ、
測っているのは「自他弁別」ではなく単なる「振幅やスペクトル形状の違いへの
応答」になってしまう。

測定するのは、条件A と条件B とで ψ 側の応答（例: 局所位相応答、局所励起性
の変化、`deriveReafferenceComparison` 型の一致/不一致指標）が統計的に区別
できるかどうかである。

### 採用する機械判定規則

自前の閾値を発明せず、`Aeterna-Genesis/docs/EMERGENCE_LEVELS.md` の規則を
そのまま採用する。

- **L2**: `localized_components > 0 AND winding_defects_detected AND persistence > τ_min`
- **L4**: `tracked_id_lifetime > τ AND inside_outside_contrast > θ AND recovers_after_perturbation`

これらの閾値 τ_min, τ, θ は測定器が K5 実装より前に凍結され、事前登録される
（`Crystal-Genesis` の事前登録方式）。実測を見てから閾値を調整することは
禁止する。

### 完了条件

- 測定器（判定規則・閾値・条件A/Bの構成）が K5 の結合実装より前に凍結されている
- 零仮説（条件Aと条件Bが区別不能）が事前登録されている
- null 結果（区別できなかった場合）が正式に記録される

### 決定的反証子

エネルギーとスペクトルを揃えた条件で、条件Aと条件Bの応答差が零仮説と
統計的に区別できない場合、**自他境界は観測されなかった**。それを結論として
`docs/vessel/white-ceilings.md` に記録し、K7 に引き継ぐ。

## この設計が答えない問い

- 区別が観測された場合に、それが「生命的閉路」と呼べるかどうかの最終判定。
  これは K7〜K8 の主張の階段（`claim-ladder.md`）に従って、観測された事実の
  水準（L2 or L4 相当）としてのみ記述され、生命・意識・自己の確定的な主張には
  拡張しない（`VESSEL_CHARTER.md` §5）。
- χ を複数持つ場合の設計。単一の外部媒質による K5〜K6 が完了するまで、
  複数媒質への拡張は開始しない（`Aeterna-Genesis` の「Level N の後に Level N+1
  の機能を追加してはならない」原則）。
