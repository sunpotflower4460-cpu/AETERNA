K14節「L2再測定」に応じる文書。

## なぜこれが必要か

K7追加実験はtau_min=500を「1/ν₀≈667tickという散逸の自然な時間スケールに
近い、切りのよい値」として選んだが、これは実測前に決めたとはいえ、
K7自身が観測した持続34〜39tickという値を意識した選定だったことは否定できない。
K14ではtau_minを`src/pure/emergence/deriveTauMin.ts`（K7の観測値を一切
参照しないコミットバリア付き）で機械的に導出し、K9・K10が可能にした
N=64/128/256での系サイズ非依存性を初めて見る。

## 使用する器

K9〜K13を揃えた完全な構成: ψ+κ13の世界χ（実在の2次元場、分布境界、
ラビ回転）。`src/pure/world/{worldField,distributedBoundary,worldTick}.ts`
をそのまま使う。

## 固定するパラメータ（実験を見る前に決める）

| パラメータ | 値 | 選定理由 |
|---|---|---|
| N（ψ・χとも） | 64, 128, 256 | 系サイズ非依存性を見る3点。K9・K10が可能にした規模 |
| α（ψ・χとも） | 1 | 全フェーズで一貫 |
| g（ψ・χとも） | 4 | K7・K13と同一の代表値 |
| ν₀（ψ・χとも） | 0.15 | K7・K13と同一値 |
| κ, ρ（ψ・χとも） | 1, 0.3 | K5〜K13の代表値 |
| ω（駆動、χのみ） | 3 | K7・K13と同一値 |
| 駆動振幅 | 0.3 | 同上 |
| k（分布境界のセル対数） | 4 | K13と同一値 |
| λ（結合強度） | 20 | K5・K6・K13と同一の代表値 |
| dt | 0.01 | 全フェーズで一貫 |
| **tau_min** | `deriveTauMin(3, 0.15)` = 6.667時間単位 = **667 tick**（機械的に導出、実測値からの逆算ではない） | 上記参照 |
| maxLocalizedFraction | 0.3 | K7の凍結値を再使用 |
| totalTicks | 2000 | tau_min(667tick)の約3倍。持続が閾値を超えるかどうかを、遷移過程に十分な余裕を残しつつ判定できる長さ（K13と同一の考え方） |
| seed | 1〜10（10 seed） | K12・K13と同じ規模のアンサンブル |

## 測定する量

- **L2**（K7の操作化そのまま）: `winding_defects_detected AND
  localized_components>0 AND persistence>tau_min`
- 系サイズ非依存性: 3つのNそれぞれでのL2満足seed数を比較する。**判定基準
  （実行前に固定）**: 3つのN全てでL2満足seed数の割合が10%ポイント以内で
  一致すれば「系サイズ非依存」と判定する。一致しなければ、どのNで
  どう異なるかを正直に報告する（系サイズ依存性自体が一級の発見）

## 誠実な限界（先に述べる）

- 10 seedは頑健性の最小限の確認であり、統計的に確証的な検定ではない
- N=256での実行速度によっては、計算資源の制約からtotalTicks・seed数を
  実行直前に縮小する可能性がある（K12・K13と同じ、結果を見る前の
  計算量再検討という形での縮小のみ許可し、決定後は変更しない）
- L3・L4・L6は本文書の対象外（K14の別の事前登録文書で扱う）
