# K7 追加事前登録 — 自然発展下でのL2実測プロトコルとその凍結

**Status:** approved-by-continuation（うえきさんの「続きお願いいたします」を
実装続行の承認として扱う）。`docs/vessel/vessel-roadmap.md` K7節が明記した
最大の空白——「K2〜K6を通じてemergence levelの系統的な実測が一度もない」
——を埋めるための、K6と同じ事前登録規律に従う文書。この文書のあとに
実装・実行し、結果を見てから閾値・パラメータを書き換えることはしない。

## なぜこれが必要か

`docs/vessel/white-ceilings.md` は実測前に2つの仮説を書いた。

- K2 PR5（駆動J、ν=ν₀均一）: 仮説「L3到達見込み」
- K2 PR6/K3（+媒質履歴ν(x)）: 仮説「L4への候補」

K6はこれらの仮説を検証していない（reafference弁別という別の問いを
測った）。この事前登録は、**L2のみ**（L3の運動追跡・L4の内外判定と
摂動回復はまだ測定器が無いため対象外——誠実な床として明記する）を、
実際に長時間駆動したrunで初めて測定する。

## 測定器（既存のものだけを使う、新規発明なし）

- `detectVortexCandidates`（`src/pure/observe/vortexCandidates.ts`）: 既存
- `trackVortexPersistence` / `vortexPersistenceAtLeast`: 既存
- **新規に1つだけ追加する**: 局在性チェック（`localized_components > 0`の
  操作化）。「最終tickでの候補セル数が全plaquette数の`maxLocalizedFraction`
  未満」という単純な基準。既存の`detectVortexCandidates`の出力をそのまま
  数えるだけで、新しい物理量は導入しない。

## L2判定規則（Aeterna-Genesis/docs/EMERGENCE_LEVELS.mdをそのまま採用）

```
L2 = localized_components > 0 AND winding_defects_detected AND persistence > tau_min
```

この事前登録における操作化:

- `winding_defects_detected` = 実行中の少なくとも1tickで
  `detectVortexCandidates`が非空の配列を返す
- `localized_components > 0` = 最終tickでの候補セル数が
  `0.3 * N^2`未満（かつ`winding_defects_detected`により>0個保証済み）
- `persistence > tau_min` = `vortexPersistenceAtLeast(tau_min)`が
  `satisfied: true`を返す

## 固定するパラメータ（実験を見る前に決める）

物理定数はK5/K6のテストで使った代表値のスケールを踏襲し、
L2実測専用にチューニングしない。

| パラメータ | 値 | 選定理由 |
|---|---|---|
| N | 10 | K5/K6のN=6より広く、複数の局在構造が入る余地を持たせる。渦の追跡そのものはL3以降の課題なので、これ以上大きくする理由はない |
| α | 1 | 全フェーズで一貫して使ってきた値 |
| g | 4 | 非線形項が渦・局在構造を支えるために十分な強さ（K5/K6の g=1 はCayley/CN検証用の小さい値だった）。damped GPE文献で渦が動くとされる領域に合わせた、控えめだが非自明な値 |
| ν₀ | 0.15 | 中程度の散逸。1/ν₀ ≈ 6.67 時間単位 ≈ 667tick が散逸の自然な時間スケールになる |
| κ, ρ | 1, 0.3（媒質履歴あり条件）／ 0, 0（媒質履歴なし対照） | K5/K6と同じ代表値。「あり/なし」の対比そのものが実験設計 |
| dt | 0.01 | 全フェーズで一貫 |
| 駆動 J | 空間一様（全セル同振幅・同位相）、振幅0.3、ω=3、runの全期間にわたり持続 | Genesisの「入れてよいもの」リストの外部流入に該当。空間形状を一様にすることで、どの模様が生じるかを駆動の形で先回りしない（対称性の破れは初期状態のseed付き微小ノイズのみに由来させる） |
| λ（χ結合） | 20（K5/K6と同じ代表値） | 交換結合ありの条件でのみ使用 |
| M, shiftCellsPerTick | 24, 2（往復12tick） | K5と同じスケール |
| tau_min | 500 tick | 1/ν₀ ≈ 667tick という散逸の自然な時間スケールに近い、切りのよい値として選ぶ（実測を見てから選んだ値ではない） |
| totalTicks | 1200 | tau_minの2倍強。持続が閾値を超えるかどうかを、遷移過程に十分な余裕を残しつつ判定できる長さ |
| maxLocalizedFraction | 0.3 | 「完全に乱流化していない」の単純な操作化。実測後に調整しない |
| seed | 1〜5（5個のseedで実行し、いずれか1つでもL2を満たせば「観測された」と報告する。複数解釈が誤解を招かないよう、満たしたseed数を必ず併記する） | 単一seedへの偶然の依存を避けるための最小限のアンサンブル |

## 比較する条件（2条件、既存仮説に直接対応）

**条件1（最小構成、対照）:** ν=ν₀均一（κ=ρ=0）、χなし（結合なし）。
`docs/vessel/white-ceilings.md`のK2 PR5仮説（L3見込み）に対応する構成の
うち、L2部分だけを見る。

**条件2（最大構成）:** 媒質履歴あり（κ=1,ρ=0.3）、χあり（λ=20）。
K3仮説（L4候補）とK5（物理的閉路）を組み合わせた、現時点でこの器が
持つ全自由度を使う構成。

条件1でL2が観測されず条件2で観測されれば、媒質履歴・交換結合が
局在構造の獲得に寄与した可能性を示す（確証ではない——単一の比較であり、
多重比較補正も頑健性の網羅的検証もしていないことを明記する）。

## 誠実な限界（先に述べる）

- L3（自発運動）・L4（内外判定・摂動後回復）は測定器が無いため今回は
  測らない。「L2は満たしたがL3/L4は未測定」という結果になりうる
- 駆動の空間一様性は「模様の形を先回りしない」ための選択だが、
  一様駆動そのものが対称性を意図的に単純化した境界条件であることは
  事実である
- 5 seedは頑健性の最小限の確認であり、統計的に確証的な検定ではない
- κ・ρ・λ・g等の値は「代表値」として選んだのであり、パラメータ空間の
  網羅的探索ではない。異なる値では違う結果が出うる

## 完了条件

- 満たした場合、その渦候補の位置・符号・持続tick数を生データとして記録する
- 満たさなかった場合、それも一級の結果として記録する（`docs/vessel/
