## なぜこれが必要か

K7追加runは「媒質履歴ν(x)ありがν(x)なしより持続優位性を示す（ただし絶対値としては
tau_min=500に遠く及ばない）」ことを実測し、探索的follow-up（`naturalEmergenceIsolation.
test.ts`）でその優位性の**ほぼ全てがχ由来**であることを確認した。つまり「媒質履歴が
何も買っていない」という実測は、（a）時間スケールの選び方が悪かっただけなのか、
（b）チャンネルの置き場所（ν(x)という特定の式形）自体が悪いのか、を切り分けていない。
K12はこの2つの仮説を分離する。

- **腕A**: 同じν(x)のまま、時間スケール（ρ）を大きく振る。K7が使ったρ=0.3は
  1/ρ≈333tick、K7のtotalTicks=1200に対して十分速い。K9・K10がN=64,128・
  10⁴〜10⁶tickを実用的にした今、K7では試せなかった「ν0よりさらに遅い記憶」を
  試す。
- **腕B**: ν(x)を凍結し（κ=0）、新しい第二のチャンネルg(x)（`docs/vessel/
  K12-memory-channel-adr.md`で式を確定済み）を代わりに動かす。

## 測定器（既存のものだけを使う、新規発明なし）

- **L2**: `detectVortexCandidates` + `checkLocalization` + `vortexPersistenceAtLeast`
  （K7と同一の操作化、`docs/vessel/K7-natural-emergence-preregistration.md`の
  L2判定規則をそのまま再掲・再使用する）
- **L3**: `trackVortices` + `evaluateL3`（`src/pure/observe/vortexTracking.ts`、

  `docs/vessel/K11-freeze-declaration.md`が要求する「使用した具体的な値を
  結果とともに必ず明記する」に従い、下表で`maxDisplacementCells`を確定する）

新しい測定器・新しい判定式は導入しない。K11で凍結済みのものだけを使う。

## L2/L3判定規則

```
L2 = localized_components > 0 AND winding_defects_detected AND persistence > tau_min
L3 = com_velocity != 0 AND circulation != 0   (K11: `evaluateL3`)
```

操作化（K7と同一）:
- `winding_defects_detected` = runの少なくとも1tickで`detectVortexCandidates`が
  非空配列を返す
- `localized_components > 0` = 最終tickでの候補セル数が`0.3 * N^2`未満
- `persistence > tau_min` = `vortexPersistenceAtLeast(tau_min)`が`satisfied: true`
- L3 = `trackVortices`の出力に`evaluateL3`をかけ、`satisfiesL3: true`の追跡IDが
  runの中に**1つでも**存在すること

### 実行前の計算量再検討（結果を見る前の改定）

`src/pure/emergence/memoryChannelSweep.ts`実装後、N=64・spectral solverでの
実測速度が129 tick/s（K9の実測とほぼ整合）と判明した。当初のtotalTicks=20,000では
7設定×10 seed×2腕=140 runで約6時間を要する。実験結果を一切見ていない段階で、
実行時間の見積もりのみに基づきtotalTicksを20,000→8,000へ改定する（約2.4時間）。
ρ=0.003系列の過小分解能という結論は変わらない（8,000でも20,000でも「1回分の
緩和時間に届かない」という同じ質的結論）。ρ=0.03系列の分解能は6回→2.4回に
低下する——この変更も結果として明記する。この改定は、K10がN=128×10⁶tickの
代わりに測定した速度から300,000tickへ縮小した判断、K11が観測器つきN=128検証を
10,000tickの代わりに2,000tickへ縮小した判断と同じ種類の、計算資源制約に基づく
事前の（結果を見た後ではない）縮小である。

## 決定的反証子の操作化

各治療設定（A-1〜A-6、B-1〜B-6）について、10 seed中「L2を満たしたseed数」
「L3を満たしたseed数（少なくとも1つの追跡IDが`satisfiesL3`）」を対照
（A-control、B-controlそれぞれ）の同じ2つの数と比較する。

**「区別できない」の操作化**: 治療設定のL2満足seed数が対照のL2満足seed数**以下**、
かつL3満足seed数も対照のL3満足seed数**以下**であれば、その設定は対照と
「区別できない」と判定する。治療設定がどちらかの指標で対照を**上回れば**
「区別された」と判定する（統計的検定ではない、K6/K7と同じ単純な操作的比較——
多重比較補正はしていないことを明記する）。

腕A・腕Bのどちらについても、**全治療設定**が対照と区別できなければ、
「この白では記憶チャンネルは構造の源ではない」と`docs/vessel/white-ceilings.md`に
書く。これはK3仮説（L4候補）の棄却であり、一級の結果。

## 誠実な限界（先に述べる）

- **N=128は今回実行しない**。完了条件が要求するN∈{64,128}のうちN=64のみを
  実行する。N=64での結果に基づき、追加のN=128 runが必要かどうかを次のチェック
  ポイントで判断する
- **totalTicks=8,000（実行前に20,000から改定）はρ=0.03・ρ=0.003系列を
  意図的に過小分解能のまま走らせる**。ρ=0.003は1/ρ≈33,333tickに対し
  0.24緩和時間分、ρ=0.03は1/ρ≈3,333tickに対し2.4緩和時間分しかない。
  これらの系列で「効果なし」という結果が出ても、それは「この時間スケールでは
  効果がない」という結論ではなく「この長さでは測れなかった」という結果である。
  両者を区別して報告する
- L4（内外コントラスト・摂動回復）・L6（自己維持閉環）は今回測定しない
  （L2/L3のみが完了条件の対象）
- g0=4・g1=8という腕Bの具体的な値は「代表値」として選んだのであり、
  パラメータ空間の網羅的探索ではない
- 10 seedは頑健性の最小限の確認であり、統計的に確証的な検定ではない
- 「区別できない」の操作化は単純なseed数比較であり、効果量やp値による
  厳密な統計的検定ではない
