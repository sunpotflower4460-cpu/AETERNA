# K12 腕C設計文書 — 伝播記憶 α(x)（実装なし、設計のみ）

**Status:** design-only, not-approved-for-implementation。`docs/vessel/
K-series-II-brain-and-universe-plan.md` K12節腕Cの明文指示「本期では ADR と
数値解析の設計文書までとし、実装は腕A・腕Bの結果を見てから別の白として扱う」に
従う。この文書はコードを一切変更しない。承認は「この設計で実装してよい」を
意味しない——腕A・Bの結果が出た後、あらためて実装の是非を判断する。

## 動機 — なぜα(x)は「最も脳らしい可塑性」か

ν(x)（K3、散逸の履歴）とg(x)（K12腕B、非線形結合の履歴）はどちらも
**その場に留まる**局所量である。α(x)（分散係数、線形項 i·α·∇²ψ の係数）を
空間変化させると、「よく通った経路は伝わりやすくなる」という、経路依存の
可塑性——ヘッブ則的な神経可塑性に最も近い性質——が原理的に表現できる。
これがν(x)・g(x)と並ぶ「第三の記憶チャンネル候補」として挙がる理由である。

## なぜK9のスペクトル分解を壊すか

`src/pure/field/linearCayleySpectralStep.ts`の高速化は、トーラスの計量
（`dA = r*(R+r*cos(theta))*dTheta*dPhi`）とLaplace-Beltrami作用素の係数が
**phi方向に依存しない**（theta方向にのみ依存する）という事実に依存する。
この並進不変性により、phi方向のFFTが作用素を対角化し、残るtheta方向の
巡回三重対角系だけを解けばよくなる（K9のADR相当の導出、
`src/pure/field/linearCayleySpectralStep.ts`のモジュールdoc参照）。

α(x)がphiに依存する一般形になると、この並進不変性が失われる。phi方向の
FFTはもはや作用素を対角化しない——K9の高速化そのものが前提から崩れる。

## 提案する離散化（実装しない、設計のみ）

### 発散形式と対称transmissibility

連続の式 `∇·(α(x)∇ψ)` を有限体積法で離散化する標準的な手法として、
セル境界ごとに**面での透過率（transmissibility）**を定義する:

```
(∇·(α∇ψ))_i ≈ sum_{j: neighbor of i} T_ij * (psi_j - psi_i) / dA_i

T_ij = 2 * alpha_i * alpha_j / (alpha_i + alpha_j) * (face area) / (cell spacing)
```

（調和平均。算術平均 `T_ij = (alpha_i+alpha_j)/2 * ...` も候補だが、調和平均は
「直列抵抗」の物理的類推——低いαのセルがボトルネックになる——を持ち、
拡散係数の空間変化を扱う数値解析文献での標準的選択である。どちらを選ぶかは
実装ADRで決めるべき未決定事項として残す。）

**対称性の保証**: `T_ij = T_ji`（分子・分母とも i,j に対して対称）なので、
離散作用素の行列は対称になる。これは`laplaceBeltrami.ts`が現在保証している
自己随伴性と同じ性質を、α(x)が非一様でも保つ。自己随伴性が保たれれば、
Cayley変換がユニタリになるという証明（K2 PR3の核心）はそのまま使える——
**保存則の破れではなく、解法の遅さだけが問題になる**。

### 提案する線形解法

一様αの厳密解（K9のスペクトル解）を**前処理**として使う、前処理付き
共役勾配法（PCG、対称作用素なので）またはより一般のKrylov部分空間法
（GMRES等）。物理的直感: α(x)が一様αからあまり大きく逸脱しなければ、
一様α版のCayleyステップは真の解にかなり近い出発点を与え、反復回数を
少なく抑えられる。

## 危険性（この設計を実装として承認しない理由）

**tolerance が結果に影響する隠れパラメータになる。** K9・K5・K12腕A/Bまでの
全ての線形解法（密LU、スペクトル、厳密な巡回シフト、厳密なラビ回転）は
**厳密解**か**解析的に保証された精度**を持ち、「どこまで反復すれば十分か」
という自由パラメータを一切持たない。反復法は本質的に「収束したとみなす基準」
を必要とし、この基準の選び方（tolerance・最大反復回数）が物理的結果に
定量的に影響しうる。これは`AGENTS.md`が禁じる「物理の破れの隠蔽」ではないが、
「実装の詳細（収束判定）が物理的結論を左右する」という、この計画がここまで
慎重に避けてきた種類のリスクである。腕A・Bの結果を見ずに実装へ進むと、
このリスクを評価する前にコードが先行してしまう。

## この設計文書が答えない問い（意図的に）

- α(x)自身の発展則（ν(x)・g(x)と同型の凸結合ODEにするか、伝播そのものに
  応答する別の量にするか）— 未決定。「よく通った」の操作化（|∇ψ|²の履歴か、
  群速度に関連する量か）も未決定
- 調和平均か算術平均か
- 前処理付きCGの収束判定基準の具体的な値
- 自己随伴性の数値検証テスト（K2 PR2の`laplaceBeltramiSelfAdjoint.test.ts`
  と同型のテストが必要になる）の具体形

これらは、腕A・Bの結果を見た上で実装を進めると決まった場合に、K5・K12腕Bと
同じ規律（ADRで確定してから実装）に従って別途決定する。
