# 天井の地図（White Ceilings）— K7

**Status:** docs-only, 仮説段階。`Aeterna-Genesis/docs/WHITE_CEILINGS.md` の
方法論をそのまま AETERNA に適用する。実測値は K2〜K6 の実装が進むごとに
この表を埋める。**現時点の内容はすべて仮説（Frontier/F）であり、測定
（Validation/V）ではない。**

## 方法論

各「白」（固定された場・法則の組）について、以下を記録する。

1. どこまで届いたか（到達 Emergence Level, `Aeterna-Genesis/docs/EMERGENCE_LEVELS.md`
   の L0〜L8）
2. なぜそこで止まるか（機構による説明。閾値の調整不足ではなく、その白が
   持たない自由度を名指しする）
3. 次に足りない原因（別の白でなければ届かないのか、同じ白のパラメータ探索で
   届くのか）

## 参照: 家系の既知の天井（`Aeterna-Genesis` より、そのまま引用）

| 白 | 到達レベル | 停止理由 |
|---|---|---|
| g001 TDGL（緩和勾配流） | L2 | 運動量・移流がなく、自発運動が出ない |
| damped GPE（減衰駆動 GPE） | robust L3 | `i` 項を保つため渦が動く。50-75%のrunで、3解像度で頑健 |
| g002 Boussinesq | coherent L3 | 流れはあるが、大域的なロールは局在した個体ではない |
| CGL（複素Ginzburg-Landau） | spiral-defect turbulence, < L4 | turbulent ≠ coherent |
| Swift-Hohenberg | L4-static | 自己修復する局在個体だが、変分型のため動かない。局在化は seed 由来 |
| Gray-Scott | L7-partial | 自己複製するが、遺伝可能な内部自由度を持たない |

**最重要知見（Genesis の言葉をそのまま引用）**: 「個体性（L4）と自発運動（L3）
は独立した二つの軸で、単純な白は片方を得るともう片方を失う」。両方を同時に
持つ白は、調査した24リポジトリのどこにもまだ存在しない。

| 白 | 方程式 | 仮説上の到達レベル | 根拠（仮説） |
