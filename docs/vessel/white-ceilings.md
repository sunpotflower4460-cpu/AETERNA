# 天井の地図（White Ceilings）— K7

**Status:** docs-only, 仮説段階。`Aeterna-Genesis/docs/WHITE_CEILINGS.md` の
方法論をそのまま AETERNA に適用する。実測値は K2〜K6 の実装が進むごとに
この表を埋める。**現時点の内容はすべて仮説（Frontier/F）であり、測定
（Validation/V）ではない。**

## 方法論

各「白」（固定された場・法則の組）について、以下を記録する。

1. どこまで届いたか（到達 Emergence Level, `Aeterna-Genesis/docs/EMERGENCE_LEVELS.md`
   の L0〜L8）
2. なぜそこで止まるか（機構による説明。閾値の調整不足ではなく、その白が
   持たない自由度を名指しする）
3. 次に足りない原因（別の白でなければ届かないのか、同じ白のパラメータ探索で
   届くのか）

## 参照: 家系の既知の天井（`Aeterna-Genesis` より、そのまま引用）

|---|---|---|

| Swift-Hohenberg | L4-static | 自己修復する局在個体だが、変分型のため動かない。局在化は seed 由来 |
| Gray-Scott | L7-partial | 自己複製するが、遺伝可能な内部自由度を持たない |

**最重要知見（Genesis の言葉をそのまま引用）**: 「個体性（L4）と自発運動（L3）
は独立した二つの軸で、単純な白は片方を得るともう片方を失う」。両方を同時に
持つ白は、調査した24リポジトリのどこにもまだ存在しない。

## K7 天井の地図（到達レベル・停止理由・次に足りない原因）

上の「現時点でのステータス」表を、K7が要求する3列（到達レベル・停止理由・
次に足りない原因）に整理し直す。**最も重要な結論を先に書く: K2〜K6を通じて
自然な長時間発展のもとでemergence levelを実際に測定したことは、ただの
一度もない。** これは怠慢ではなく、以下の理由による誠実な現状である。

| 白 | 到達レベル（実測） | 停止理由（機構） | 次に足りない原因 |
|---|---|---|---|
| K2 PR2（器のみ） | 判定対象外 | 時間発展そのものが存在しない | PR3の実装（既に完了） |
| K2 PR3（保存部のみ） | 判定対象外 | 保存系はエネルギー注入源を持たず、初期条件の自由分散が続くだけで「白」として持続しない | PR4〜PR5の実装（既に完了） |
| K2 PR4（+散逸） | 判定対象外 | 駆動なしの散逸系は単調減衰する吸収体であり、持続構造を生まない | PR5の実装（既に完了） |
| K2 PR5（+駆動J、ν=ν₀均一） | **未測定**（L3仮説は依然として実測0件） | 測定を行っていない——単体テストは既知パターン（象限位相等）でのvortex candidate検出器の正しさを確認しただけで、駆動下で自然に何が生じるかを長時間観測していない | 十分な長さ（往復遅延やτ_minより十分長い）の専用run。K6と同様の**別途の事前登録**（探索してから閾値を選ぶことを避けるため）が必要 |
| K2 PR6 / K3（+媒質履歴ν(x)） | **未測定**（L4候補仮説は依然として実測0件） | 同上——媒質履歴の非負性・局所応答性は確認したが、それが実際に個体性（L4: 追跡可能な境界・摂動後回復）を生むかどうかを長時間runで見ていない | 同上。K3固有の決定的反証子（`vessel-roadmap.md` K3節: ν固定対照との個体性指標の区別）も未実施 |
| K2 PR7 / K4（読み取り専用観測） | 判定対象外（測定器） | 測定器を凍結しただけで、測定を実行していない | 上記のPR5/K3のrunを、この測定器で実際に見る |
| K5（物理的閉路：χ・𝒮・対称結合） | **未測定**（L2/L4は実測0件） | K5完了時点でK6が測ったのはreafference弁別（局所密度差）のみで、閉じたループ自体がPR7の測定器で見て個体性・渦を示すかは別途未観測。K6のL2チェックは`tau_min`が観測窓（15tick）を超えていたため判定不能だった（実測後に発覚、事後調整せず） | `tau_min`より十分長い観測窓を持つ専用run（K6と同じ事前登録規律で） |
| K6（reafference弁別） | 判定対象外（自他弁別の測定であり、emergence levelの測定ではない） | — | 上記「誠実な限界」節・`vessel-roadmap.md` K6節参照 |

**この地図が示す一番正直な事実:** AETERNAのpure physics coreは、K2〜K6を
通じて「動く」（駆動・散逸・媒質履歴・交換結合が全て検証済みで正しく動作
する）ことは厳密に証明したが、「何が創発するか」はまだ一度も系統的に
観測していない。これは天井が低いことの証拠でも高いことの証拠でもなく、
**測定していないという事実**である。Genesisの家系知見（個体性L4と自発
運動L3は独立軸で、単純な白は片方しか持てない）にAETERNAが当てはまるか
どうかも、したがって未確定のまま残る。

**なぜここで測定を急がなかったか:** K6で払った代償（较正の不完全さ、
L2のtau_min設計ミス）から学んだのは、「測定器を作ったら次は事前登録
してから測る」という規律を飛ばすと、あとから誠実に書き直す羽目になる
ということである。K7の役割は地図を描くことであり、新しい実測を無計画に
増やすことではない。この地図の空白こそが、K7の成果物である。
