- v0.1 — 初版

**目的:** AETERNAから作為的要素を取り除き、「トーラスの中に物理として置いたものが流れる」状況だけで成り立つコアを分離する。

**基本原則(これが全てに優先する):**

1. 「これが必要だからこう動く」型のロジックを一切持たない
1. エネルギーの出入りは全て帳簿に記録され、毎tick閉じる
1. 観測は力学に一切影響しない(読み取り専用)
1. 観測者は「こう見える」を報告でき、「確定」はしない
1. Aeterna本体の表現には制約をかけない

## 2. 場の方程式

トーラス上の複素場 ψ(x, t)。

```
∂ψ/∂t = i(α∇²ψ − g|ψ|²ψ)  −  νψ  +  J(x, t)
         └─ 保存部(ハミルトニアン) ┘   └散逸┘  └外部駆動┘
```

- **保存部** `i(α∇²ψ − g|ψ|²ψ)`:非線形シュレディンガー(Gross-Pitaevskii)型。この部分単独ではノルムとエネルギーが厳密に保存される。渦(位相欠陥)を自然に支持する
- **散逸** `−νψ`:唯一のエネルギー出口。失われたエネルギーは媒質の熱帳簿へ移記される
- **外部駆動** `J(x,t)`:唯一のエネルギー入口。シナリオ=Jの仕様であり、それ以外の経路で場に触れることを禁止する
- **∇²** はトーラス計量(R, r)に基づくラプラシアン。曲率は幾何由来なので維持

**現行コードからの変更点:** 現行は `∂ψ/∂t = iα∇²ψ + βψ − γ|ψ|²ψ` で、β(無からのゲイン)と実数係数の非線形減衰が混在。新設計では非線形項を保存部(虚数側)に移し、ゲインβを廃止して明示的な駆動Jに置き換える。

## 3. 積分器(クランプの撤廃)

現行のmaxDelta・amplitudeClampは「物理の破れの隠蔽」なので全廃。代わりに数学的に正しい積分:

**Strang分割(1tick):**

1. 非線形位相回転 半ステップ:`ψ ← ψ · exp(−i g|ψ|² dt/2)` — 厳密にノルム保存
1. 線形拡散 1ステップ:Crank–Nicolson(無条件安定・ノルム保存)、または陽解法なら CFL条件 `dt ≤ h²/(4α)` をコンストラクタで強制
1. 非線形位相回転 半ステップ
1. 散逸:`ψ ← ψ · exp(−ν dt)` — 厳密な指数減衰。減少分エネルギーを帳簿へ
1. 駆動:`ψ ← ψ + J·dt`。注入エネルギーを帳簿へ

**成立条件:クランプ機構そのものがコードに存在しない。** NaNや発散が出たらそれは実験の失敗として記録される事実であり、隠さない。

## 4. 媒質の履歴(weak plasticityの物理法則化)

現行の4チャンネル分類(vortexTrace等)は観測カテゴリの混入なので廃止。**1本の物理則**に統一:

```
∂ν(x)/∂t = −κ · Φ(x)  +  ρ · (ν₀ − ν(x))
```

- **Φ(x) = ν(x)·|ψ(x)|²**:その地点の局所エネルギー散逸率。散逸項 −νψ が実際に捨てているエネルギーそのもの(定義であり追加の仮定ではない)
- κ:媒質の可塑率。「よく通った道は抵抗が下がる」— 川が地形を削るのと同じ型の物理
- ρ:基準値ν₀への緩和(自然な忘却)

**非負性はクランプでなく構造から出る:** Φ=ν|ψ|² なので、削られる量は最初からνに比例している。ν→0 で散逸自体が消えて削るものがなくなり、ρν₀ が押し戻すため、連続系では負に到達できない。

**離散ステップでの飛び越え対策も厳密積分で解決する(クランプ禁止):** tick内で |ψ|² を凍結すれば、この式はνについて線形ODEとなり解析解を持つ:

```
ν(t+dt) = ν* + (ν(t) − ν*) · exp(−(κ|ψ|² + ρ)·dt)
ν*      = ρν₀ / (κ|ψ|² + ρ)
```

指数関数による緩和なので、初期値が正なら **数学的に厳密に ν > 0**。散逸を exp(−νdt) で厳密に解くのと同じ思想であり、max(ν, 0) のようなガードはコードに存在してはならない。

これは場→媒質のフィードバックだが、**観測的でなく物理的**(媒質が通過エネルギーに応答する。実在材料の加工軟化と同型)。記憶を「作る」のではなく、履歴を持つ媒質を「置く」。

## 5. 帳簿(ノルムとエネルギーの二本立て)

NLS型の場には独立な保存量が2つある。帳簿は両方を別々に追う:

**ノルム帳簿(量):**

```
N = Σ |ψ|² · dA        (dA = 格子セル面積、トーラス計量による)

N(t+1) = N(t) + driveWork_N − dissipationLoss_N + residual_N
```

**エネルギー帳簿(ハミルトニアン):**

```
H = Σ ( α|∇ψ|² + (g/2)|ψ|⁴ ) · dA

H(t+1) = H(t) + driveWork_H − dissipationLoss_H + numericalDrift_H + residual_H
```

**帳簿項の定義:**

|項               |意味                             |性質               |
|----------------|-------------------------------|-----------------|
|driveWork       |駆動Jが場にした**符号付き**の仕事(実測差分)      |物理的入力。逆位相なら負になる  |
|dissipationLoss |散逸νにより媒質熱へ移った損失(実測差分)          |物理的出力。ν>0なら常に非負  |
|numericalDrift_H|保存ブロック(Strang分割ステップ1〜3)前後のHの実測差|**物理ではなく計算上の観測項**|
|residual        |上記すべてを記帳した後の残差                 |実装バグ・帳簿不成立の検出用   |

**記帳規則:**

1. **Nについて:** 保存ブロックは準厳密にNを保存する(位相回転は厳密、Crank–Nicolsonも線形部でノルム保存)。residual_N は浮動小数点誤差レベルであること
1. **Hについて:** Strang分割は部分ステップごとに構造を保つが、合成解は元のNLS全体のHを毎tickでは保存しない。O(dt²)のドリフト・振動が出るのが**正しい挙動**である。これを許容誤差に隠さず、`numericalDrift_H` として毎tick実測・記帳する。帳簿自体は厳密に閉じたまま、スキームの限界が事実として記録される
1. **駆動・散逸の記帳は実測差分のみ:** 各ステップ適用前後の N, H の差をそのまま記帳する。|J·dt|² のような事前計算は禁止。ノルム変化は 2Re(ψ*·J)dt + |J·dt|² であり、場と駆動の位相が逆なら負になる(駆動が場からエネルギーを抜く)。これは物理として正しい現象であり、符号付きの `driveWork` という名がそれを正直に表す
1. **媒質履歴ステップ(νの変化)は場に直接触れないため N, H を変えない**ことも毎tick検証する(変えていたら実装バグ)

**濫用禁止条項:** `numericalDrift` は保存ブロックの数値積分誤差を記録するための項であり、散逸・駆動・媒質履歴・実装バグによる不一致を吸収するために使ってはならない。保存ブロック以外で生じた差は residual に現れ、帳簿不成立として扱われる。

**成立条件:** residual_N・residual_H が許容誤差(例 1e−9 × |X|)内であることを毎tick検証。破れたら実験は「帳簿不成立」として記録される。現行 `waveCapableMedium` のenergy ledger実装はこの思想に近いので流用可能。

## 9. 創発の観測(観測者は「こう見える」まで)

以下は数値として観測・報告する。確定はしない:

1. **自発構造** — 駆動なし・ランダム初期条件からの渦形成と寿命分布。「シナリオに作らされた構造」と区別するため、自由発展クラスと駆動クラスを実験として分離する(渦数6.75の3シード一致問題への対処)
1. **履歴依存** — 同一パルスをt₀とt₁(間に活動を挟む)で与え、応答の差を測る。媒質履歴が機能していれば差が出る
1. **自己維持** — 駆動を切った後、構造が受動減衰時間 1/ν を超えて持続するか
1. **統合** — 離れた領域間の相関が偶然水準を超えるか

これらの数値条件を事前定義しておけば、自動スイープ側が「条件を満たしたパラメータ領域」を列挙して報告できる(優劣判断はしない)。
